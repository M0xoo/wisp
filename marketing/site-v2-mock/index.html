1DeclareNew

Your agent team, as code in your repo.

Agents, crew, machines, tools, rules and workflows live in .wisp/: files that reference each other, with variables and reusable modules, like infrastructure as code. Review it in a PR, apply it anywhere. Clicking in the app and editing the file change the same thing.

AgentsNamed profiles: harness, model, effort, mode, tools. "reviewer" means the same thing everywhere.
CrewLong-lived teammates with a role, a schedule, a notebook and a team they delegate to.
MachinesYour laptop, a dev box over SSH, a cloud computer. Say where each task runs.
WorkflowsTasks with needs, conditions, fan-out across agents, goals, retries and one budget.
ToolsMCP servers and wisp's own tools, per agent. Secrets stay out of the file.
RulesWho may start what from Slack or Telegram, spend limits, what happens when a run fails.
