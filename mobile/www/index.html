Keys on this phone advanced

The app signs in with these instead of your password. It makes and installs one for you; you only need this to use a key you already have.

Add a computer

Where do I find it?
  • wisp already runs there: Settings → Machines → This computer → Connect with.
  • A Mac: System Settings → General → Sharing → Remote Login shows ssh you@its-name. Turn it on while you’re there.
  • Away from home: install Tailscale on the computer and this phone, and use the name it shows.
